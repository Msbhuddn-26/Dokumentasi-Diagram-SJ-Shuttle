Dokumentasi Rekayasa Perangkat Lunak SJ Shuttle

Pusat Dokumentasi Sistem Shuttle Bus Universitas Pamulang (UNPAM). Navigasi di bawah ini akan membawa Anda ke rincian teknis dari setiap fase perancangan sistem.

Dashboard Use Case Activity Sequence Flowchart

1. Penjelasan Use Case Diagram

Use Case Diagram berfungsi sebagai cetak biru (blueprint) interaksi antara manusia (Aktor) dengan Sistem. Diagram ini mendeskripsikan secara tingkat tinggi "Siapa bisa melakukan Apa" di dalam aplikasi SJ Shuttle. Pada halaman Use Case, Anda akan melihat pengelompokan modul sistem, batasan hak akses antara Penumpang, Pengemudi, dan Administrator, serta skenario mendetail dari setiap aktivitas.

2. Penjelasan Activity Diagram

Activity Diagram menjabarkan alur kerja (workflow) dari sebuah aktivitas Use Case. Diagram ini memetakan langkah demi langkah, dari awal hingga akhir, bagaimana sebuah sistem bereaksi terhadap input dari pengguna. Halaman ini menjelaskan proses operasional seperti alur login, tata cara pemotongan saldo, hingga urutan logis saat keadaan darurat terjadi di lapangan.

3. Penjelasan Sequence Diagram

Sequence Diagram berfokus pada dimensi waktu dan komunikasi pesan antar-objek di dalam arsitektur perangkat lunak (Model-View-Controller). Diagram ini sangat teknis karena memvisualisasikan bagaimana antarmuka (Boundary), logika server (Controller/Service), dan pangkalan data (Entity) saling melempar fungsi (API/Method) dalam sepersekian detik untuk merampungkan sebuah tugas.

4. Penjelasan Flowchart Diagram

Flowchart Diagram secara murni merepresentasikan algoritma komputasi dan logika percabangan (If-Else) di dalam server. Berbeda dengan Activity yang melibatkan aktor manusia, Flowchart digunakan oleh programmer untuk memahami bagaimana mesin mengalkulasi matematika (seperti rumus jarak GPS Haversine) dan mengambil keputusan otonom secara sistematis.
